# Release and semantic versioning

## Branch and trigger model

- `main` is the release branch.
- CI runs on pushes/PRs to `main`.
- Publishing runs on tags matching `v*.*.*`.

## Semantic versioning

- The tool package version is generated by `MinVer` from git history and tags.
- Use annotated tags with `v` prefix:
  - `v0.1.0`, `v0.1.1`, `v0.2.0`, `v1.0.0`.
- For development commits after a tag, MinVer emits prerelease versions automatically.

## Trusted Publishing setup (nuget.org + GitHub)

1. On nuget.org, open the `MkDevForge.Bbt` package settings.
2. Configure Trusted Publishing for this GitHub repository and the workflow file `.github/workflows/release.yml`.
3. Ensure the workflow keeps `permissions.id-token: write` (required for OIDC exchange).
4. Add GitHub repository secret `NUGET_USER` with your nuget.org username (used by `NuGet/login@v1`).
5. Push a release tag to trigger publish.

## Release commands

```bash
git checkout main
git pull
dotnet test bbt.sln -c Release
git tag -a v0.1.1 -m "v0.1.1"
git push origin main
git push origin v0.1.1
```

## Fallback (if Trusted Publishing is not ready)

- Add GitHub repository secret `NUGET_API_KEY`.
- Replace the `NuGet/login@v1` step in `.github/workflows/release.yml` with direct `dotnet nuget push` using that secret.
